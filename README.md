Qiskit Fall Fest Challenges

This repository contains my completed Qiskit Fall Fest Challenges 1–4 using Python and quantum computing.

Challenges

* Challenge 1: Single-qubit quantum gates (X and H) and measurement.
* Challenge 2: Quantum rotation gates and measurement probabilities.
* Challenge 3: Bell states and quantum entanglement.
* Challenge 4: Comparing correlated and opposite measurement outcomes.

Technologies Used

* Python
* Qiskit
* Qiskit Aer
* Jupyter Notebook
* Matplotlib
